# Testimonial Images

To add profile pictures for testimonials, save the following images in this folder:

## Required Images:

- `jean-paul.jpg` - Profile picture for Jean Paul (Year 1 Student, RCA)
- `grace.jpg` - Profile picture for Grace M. (Fellow Student)
- `david.jpg` - Profile picture for David K. (Project Collaborator)

## Image Specifications:

- **Format**: JPG, PNG, or WebP
- **Size**: At least 96x96 pixels (will be displayed at 48x48px)
- **Aspect Ratio**: Square (1:1) for best results
- **Style**: Professional headshots or clear portraits

## Fallback:

If no image is provided, a beautiful gradient placeholder with initials will be displayed instead:

- Jean Paul → "JP"
- Grace M. → "GM"
- David K. → "DK"

The avatars will have a cyan border and will be perfectly circular with a subtle glow effect.
